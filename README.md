# BankApp

## Требования к приложению:

### 1. Аутентификация и идентификация
  - Клиент вводит номер карты при первом входе для активации
  - Система проверяет, зарегистрирована ли карта в банке
  - При первом входе клиент устанавилвает PIN-код
  - При повторном входе клиент вводи установленный ранее PIN-код или пароль
  - Блокировка после трех неудачных попыток ввода PIN-кода

### 2. Основные операции:
  - Просмотр баланса по счету 
  - Пополнение счета (ввод суммы)
  - Снятие наличных (вывод суммы)
  - Перевод между своими счетами
  - Перевод на счет другого клиента (по номеру карты)
  - Просмотр истории транзакций (последние 10 операций)

### 3. Управление счетами:
  - Клиент может иметь несколько счетов (карты, накопительный)
  - Возможность закрыть счет 

### 4. Безопасность:
  - Все операции логируются (дата, время, тип, сумма)
  - Конфиденциальные данные хранятся в зашифрованном виде 
  - Сессия завершается через 5 минут бездействия
